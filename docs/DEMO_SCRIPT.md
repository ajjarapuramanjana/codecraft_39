# Hackathon demo flow
1. Open the landing page and explain the safe-learning purpose.
2. Register a demo account and show the responsive dashboard.
3. Start a scenario, select warning clues, classify the message, and choose a safe action.
4. Show instant feedback and the saved attempt count on the dashboard.
5. Open the analyzer and submit a fictional sample. Explain the risk signals and recommended steps.
6. Explain architecture: HTML/CSS/JS → Flask routes → SQLite; optional AI runs server-side and falls back to transparent rules.
7. Mention privacy and safety: no live phishing links, no link opening, never request credentials/OTPs.
